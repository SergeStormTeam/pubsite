# Pubsite - [serge.cs.house](https://serge.cs.house).

The public facing website for the Serge Storm Chasing Team

## Overview

The site is written using the static site generator [Hugo](https://gohugo.io/). For styling, it utilizes the [Blowfish](https://blowfish.page/) theme.

## Local Development

Build the container: `docker compose up --build`
