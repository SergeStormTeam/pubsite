It is with great pleasure that we now have a public dashboard where you can view the live feed of our Zephyr Probe! To go on over to view it, you can find it [here](https://serge-zephyr-feed.cs.house/), or click on the "View Our Data Live!" at the top of your screen!

The dashboard shows 8 cells each with the data that we collect. Underneath each reading, you can see the sensor that we use to collect that data. Some cells with have the option for you to select what unit of measurement that the data is displayed as. The goal for this is to allow everyone to be able to see the environments were in, and get up to date information live on the ground. If you have any ideas for the dashboard and would like to contribute to the application, the repo for it can be found [here](https://github.com/SergeStormTeam/zephyr-dashboard)
